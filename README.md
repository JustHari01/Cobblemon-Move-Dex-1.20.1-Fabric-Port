# Cobblemon Move Dex (UNOFFICIAL) — Fabric 1.20.1

An unofficial Fabric backport of [Cobblemon Move Dex](https://modrinth.com/mod/cobblemonmovedex) by ZzhangaAo1z for Minecraft 1.20.1. Since Cobblemon 1.5.2 does not include its later native Pokédex screen, this port adds a Moves button to the compatible Cobbledex screen. It lists level-up, TM, tutor, egg, and evolution moves provided by the installed Cobblemon species data.

## Compatibility

- Minecraft 1.20.1
- Fabric Loader 0.15.11 or newer
- Fabric API
- Cobblemon 1.5.2 for Minecraft 1.20.1
- Cobbledex 1.1.0 for Minecraft 1.20.1

Install it on both the client and server for multiplayer. The Moves screen is available from Cobbledex when a Pokémon is selected.

## Install

Install the dependencies above, then place this JAR in the `mods` folder on both the client and server.
